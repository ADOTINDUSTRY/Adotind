# Adotind

Simple static homepage for a **Sign Factory** website.

## Run locally

Open `index.html` in your browser.

## GitHub Pages

This repository includes `.github/workflows/deploy-pages.yml` to deploy the site.

If you see **403 Forbidden** on your Pages URL:
1. In GitHub, go to **Settings → Pages**.
2. Set **Build and deployment** source to **GitHub Actions**.
3. Push to `main` (or re-run the **Deploy static site to Pages** workflow).
